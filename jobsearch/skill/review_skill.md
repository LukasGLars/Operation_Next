# Review Skill

## Purpose
Refine a generated CV and cover letter so that every sentence speaks directly to what this specific company is looking for, in language that reads as written by a native speaker who understood the ad.

## What you are NOT doing
- Do not invent new facts, results, or experiences
- Do not restructure the document
- Do not change which jobs or projects are included
- Do not change the opening line

## What you ARE doing
1. Re-read the job posting and identify the 2–3 things this company is actually anxious about — the real need behind the role description
2. Reframe the existing content so it answers those specific anxieties directly
3. Mirror the register of the ad — if they write plainly, write plainly. If formally, match that. Adjust vocabulary and phrasing to feel like the application belongs in the same conversation as the ad
4. Naturalise the language — rewrite anything that reads as translated or unnatural into language a native speaker would actually use

## Language-specific naturalisation

### Swedish
- Read every sentence aloud in your head. If it sounds like a translation, rewrite it
- Avoid compound nouns that don't exist in everyday Swedish
- Use the vocabulary and rhythm from the job posting itself as your guide
- Cover letters should sound like a person talking, not a document being filed
- When in doubt: shorter, simpler, more direct

### English
- Match the directness and rhythm of the approved Einride cover letter reference
- Avoid corporate phrasing — write like someone who knows what they did
- Results stay specific and concrete, never softened into vague claims

## Output
Return only a valid JSON object with no other text:
{"cv": "full CV in markdown", "cover_letter": "full cover letter in plain text"}
