## Utvalda projekt

**Macro Regime Signal & Alert System (Personligt projekt)**
Python-baserat system som hämtar dagliga makroekonomiska data från FRED (yieldkurvor, kreditspreadar, VIX, arbetsmarknadsdata), beräknar momentum och regimskiften och genererar risk-on/risk-off-signaler. AI-assisterad tolkningspipeline som levererar en daglig makroöversikt via automatiserad e-post. Backtestresultat över 10 år: Sharpe 1,85 | Årsavkastning 30,1 % | Max drawdown −24,9 %.
*Stack: Python, FRED API, Yahoo Finance, Claude API, GitHub Actions, scipy, pandas*

**VVS Faktura-app (Personligt projekt)**
Mobilanpassad webbapp för VVS-entreprenörer. Hanterar kunder, jobb och fakturor från start till slut. ROT-avdragsberäkningar, PDF-generering, Claude Vision OCR för kvittoextraktion och automatisk prisbenchmarking. Självhostad på Linux.
*Stack: Python, Flask, SQLite, Alpine.js, Tailwind CSS*

**MedTech Compliance Platform (Medskapare, 2025–Pågående)**
